# Panel de Talento — Leyva Group

Mockup funcional e interactivo para centralizar la gestión de talento y RRHH del grupo empresarial.

## Módulos

- Solicitudes y necesidades de personal
- Captación de candidatos y matching mediante IA
- Empleados, skills y documentación
- Organigramas por holding, empresa y departamento
- Coste real de personal
- Accesos y recursos digitales

## Desarrollo local

```bash
npm install
npm run dev
```

La interfaz está desarrollada con React, TypeScript, Vinext y Lucide Icons.
